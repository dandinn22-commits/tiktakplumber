# אינסטלציה תיק תק

אתר של אינסטלציה תיק תק: דף ראשי, 7 דפי ערים ו־4 מדריכים. הכתובת המתוכננת: tiktakplumber.com

## איך האתר בנוי
- `tools/source/` – הדפים המקוריים. שינוי בטקסטים של הדפים נעשה כאן.
- `tools/config.py` – פרטי העסק: טלפון, מייל, מדידה, רישיון, ביקורות ותמונות.
- `tools/guides.py` – תוכן המדריכים.
- `tools/extra.css` – תוספות לעיצוב.
- אחרי כל שינוי מריצים `python3 tools/build.py` מתיקיית האתר, ומעלים את הכול.
- לא עורכים ישירות את קובצי ה־HTML שבתיקייה הראשית. הם נוצרים מחדש בכל בנייה.

## מה חסר לפני עלייה לאוויר
1. **טלפון:** למלא את `PHONE`. כל עוד הוא ריק, כפתורי החיוג מובילים לטופס וכפתורי הוואטסאפ לא מוצגים.
2. **תמונות:** לשים בתיקיית `assets` את `logo.webp` ואת `hero-pipes.jpg`. עד אז מוצג שם העסק כטקסט. הסמל של האתר ותמונת השיתוף זמניים.
3. **טופס:** בליד הראשון מכל דומיין, FormSubmit שולח מייל אישור. צריך ללחוץ עליו, אחרת לידים לא יגיעו.
4. **גיליון לידים:** להגדיר את הסקריפט לפי ההוראות ב־`tools/apps-script.gs`, ולמלא את `SHEET_ENDPOINT`.
5. **מדידה:** למלא את `ADS_ID`, `ADS_LABELS` ו־`GA4_ID`.
6. **רכז נגישות:** למלא את `ACCESS_COORDINATOR`.
7. **ביקורות, דירוג, רישיון ותמונות עבודה:** למלא רק נתונים אמיתיים. כל עוד הם ריקים, החלקים האלה לא מוצגים.

## העלאה לאוויר
- **Hostinger:** לחבר את המאגר הזה. הקובץ `.htaccess` כבר מכין את דף השגיאה וחוסם גישה לתיקיית `tools`.
- **GitHub Pages:** בהגדרות המאגר, בפרק Pages, לבחור את הענף `main` ואת התיקייה הראשית. הקובץ `CNAME` כבר מכיל את הדומיין.
- בסוף להגיש את `sitemap.xml` בכלי של גוגל לבעלי אתרים.
